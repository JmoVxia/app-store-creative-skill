# 素材与生产

## 多来源按用途选路

| 来源 | 适合用途 | 必须说明 |
| --- | --- | --- |
| 用户提供 | 品牌、照片、产品截图、手改内容 | 版本、预期用途、可编辑范围、是否允许替换 |
| 原生采集 | App 界面、控件、编辑状态 | App／系统／设备／语言／地区、前置数据、状态和采集方法 |
| 实际处理入口 | 拼接、裁剪、去条、标注等功能结果 | 输入、调用逻辑、版本、完成信号、输出及比对依据 |
| 自有内容源 | 图文、聊天示例、列表、表格等 | 内容 ID、数据来源、非真实数据说明、语言和布局来源 |
| ImageGen | 摄影、插画、艺术主视觉、设计探索 | 实际工具、提示词、参考、输出原件、可变与保留项 |
| 互联网 | 参考研究或可使用的照片等 | URL、获取日期、参考／交付用途、使用依据和所需署名 |

缺少真实素材就提出缺口，继续不依赖它的工作。不要用网页仿制或 AI 重画的控件冒充真实 App 截图，不用人工补图冒充算法结果。参考案例不自动获得交付使用权；不随公开技能打包无再分发依据的图片、字体、私有代码或真实数据。

## 可替换的混合生产链路

结构化内容与翻译 → HTML/CSS 或图像脚本生成自有内容 → 必要时导入 App 执行真实功能 → 采集／导出并检查 → 素材样张确认 → 海报排版 → 成图检查。

HTML/CSS 适合内容源、精确文字、可视化示意和批量排版，不要求所有内容都改成网页。原生界面与真实功能结果由真实采集提供；ImageGen 负责需要创造性的位图素材。各层来源分别保留。

## 先算足，再采集

素材槽位声明宽高、等比映射、焦点／裁切锚点、完整消息或条目边界、最低清晰度及可变区域。按所有设备和目标构图反推所需源尺寸、全长、数量与安全余量，一次准备足够内容。

需要切片时记录源尺寸、各起点与高度，检查首尾覆盖、唯一性、相邻真实重叠和全长输出；数量和重叠率按实际引擎要求决定。不要以重复段落、空白或拉伸凑长。展示用叠卡与真实引擎输入可以不同，但须明确其关系，不把艺术展示片称为新的实测输入。

内容完整性和功能表达一起检查：照片不能抢占长内容主体，放大镜须对准真实目标，箭头与标注目标一致；比较图使用同源同区域同倍率。具体构图规则由该 App 的确认结果决定。

## 自动化采集

先复用合格的采集与已有入口。需要新入口时采用素材专用最小实现或隔离宿主，复用真实处理逻辑，保持正式产品行为不变；代码、编译、安装与运行遵循本次任务授权和工程规则。

每项任务记录输入及参数哈希、引擎／App 版本、设备、语言、地区、外观、前置状态、状态重置、完成信号、超时、失败原因和输出。按任务状态等待，不机械按坐标点击或重复截图。更换模拟器、设备或用户接管后，重新读取实际状态。

网页采集等待字体、图片和布局稳定，按需要预热完整内容；滚动时机、系统指示器淡出、动画、懒加载、键盘和提示条都可能影响真实输出，需控制或记录。不要人为合成不存在的行为来方便算法。缓存复用必须同时满足输入、参数、环境、引擎版本和质量检查相符；曾经 ready 或文件存在不足以复用。

## ImageGen

调用当前环境可用的生成／编辑能力，按其规则提供参考图。提示词记录用途、主题、构图、材质、光影、配色、保留项、可变项和禁用元素；不要把模型未提供的 seed、版本锁定或精确几何能力写成保证。

确认后保存原件及哈希，重复生产复用它。文字和国际化尽量由独立排版层完成。需要生成多个方向时分轮比较；重新生成的结果进入候选，不能覆盖已确认原件。艺术主视觉独立于真实功能证据。

## 素材样张关卡

按类型确认代表样张，而非每份文件逐张问：展示实际生产链路产生的内容、质感、清晰度、取景和真实效果，覆盖有压力的语言／设备。通过后再批量生产；复用已合格同规则素材，不重复确认。将样张应用回整体示意复核，避免素材单独好看却不适合版面。

## 用户替换与手改

核对改动意图与差异，回写内容源、配置、模板或素材。只提供扁平图片且无法还原时，声明固定图层、可编辑区域和国际化限制。检查受影响的语言、页面和确认，不猜测隐藏图层，也不直接覆盖下一次生产会丢失的最终 PNG。
