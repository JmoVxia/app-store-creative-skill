# 参数维度目录

这是选择性使用的设计与生产词典，不是必须逐项问完的表单。先整体理解和示意，再对影响本轮结果的关联组细化；可调查的先测量，审美问题用组合示意。每个 App 自己确定适用项、值和例外。

## 每组参数的外壳

| 项 | 记录方式 |
| --- | --- |
| 目的 | 服务哪页、哪种收益或哪个组件 |
| 值与单位 | px、比例、角度、颜色空间、字符串、枚举或内容引用；明确坐标系 |
| 作用域 | App／整套／商店位置／设备／语言／场景／素材／局部例外 |
| 来源 | 用户要求、代码／资料事实、测量、官方规格、参考或设计建议 |
| 状态 | 未知、建议、候选、已确认、受变更影响；附确认轮次 |
| 适配 | 固定项、可变项、上下限、联动关系和调整顺序 |
| 证据 | 示意图及哈希、素材 ID、测量与运行报告 |
| 验收 | 可计算检查、视觉观察、允许差异与需要用户判断的部分 |

## 使用维度目录

识别本轮真正影响效果的组，先用整体样张确定关系，再测量并保存值。维度间冲突应在示意阶段暴露，例如字数与主标题宽度、照片占比与功能证据、平板工具区与源内容长度。参数没有默认“越大越好”或“越统一越好”；判断依据是本 App 已确认的定位、表达和整体效果。
