# 设计与逐轮对齐

## 产品理解

先听用户描述，再只补问会改变结果的信息：用户与市场、核心任务和收益、差异点、商业边界、目标平台／位置／语言、现有品牌与素材、限制、时间和探索预算。暂时未知的字段保持未知，不能用建议值冒充事实。

复述理解并确认后，再核对代码、产品资料和素材。记录描述与实现不一致的地方。工程存在的功能不自动等于宣传重点；没有源码也能走资料入口。未经证实的宣传承诺不能写进已确认文案。

## 叙事与参考

以用户价值为默认主线，操作流程是可选结构。为每页记录：

| 字段 | 问题 |
| --- | --- |
| 目标 | 看完应理解或相信什么？ |
| 证据 | 用真实界面、实际结果还是艺术主视觉表达？ |
| 视觉任务 | 主体是什么，第一眼应看到什么？ |
| 场景约束 | 哪种内容不可替换，否则会丢失功能意图？ |
| 上下文 | 与前后页如何衔接，哪里重复？ |
| 完成标准 | 怎样判断这一页表达正确？ |

张数和顺序按定位决定，不机械一功能一张，不把示例项目的八张／九张写成默认值。

参考分为同类产品与跨品类视觉两条线。记录 URL、地区、语言、日期、具体画面、借鉴维度、适用理由和转化方案。功能竞品研究卖点和叙事；视觉案例研究排版、构图、材质等。参考截图不是可直接使用的交付素材。

“Apple 审美”“电影感”“高级”“饱满”等先作为意图，通过参考和示意转化成可观察的规则。官方规格、审美判断和用户偏好分别记录。

## 整体 → 关联细化 → 整体

整体候选保持可比：尽量使用同一文案和内容，明确各方向差异；在低成本阶段发现定位、风格和构图问题。需要 ImageGen 探索时使用当前环境真实可用的生成工具；不要承诺固定 seed 或不存在的控制能力。

整体选定后，按关联组细化，而非让用户逐个选坐标：

- 标题：字体／版本、字重、字号、行距、字距、断行、字面边界、对齐、宽度、各语言变体。
- 卡片：尺寸、倍率、圆角、描边、阴影、间距、遮挡、透视、内容密度。
- 内容：图文比例、完整段落／条目、图片焦点、重复度、留白、最小可读尺寸。
- 指引：箭头、标签、图标、序号的语义、样式、锚点、目标关系、避让与去重。
- 光影：光源、偏移、模糊、透明度、渐变色标、材质及层次。

关联组确认后把细节应用回完整画面及整套总览。新整体通过后，才冻结生产标准。不可把尚未渲染的文字参数当成效果已确认。

## 可复用参数记录

参数不仅是数值，还包括单位／坐标系、作用范围、来源、固定或可变、允许范围、联动处理顺序、依赖、确认轮次和验收方式。尺寸使用明确的画布像素或设计坐标，说明缩放关系；区分 CSS 行盒、字面顶边和视觉中心。

分层保存品牌约束、共享组件、位置／设备布局、语言变体、页面意图、素材槽位、具体取景和局部例外。例外须限定作用范围，不改其他页面默认行为。不要求每个项目填写所有维度，只填写会影响其成果的字段；缺失关键值不能静默补默认。

## 整改

先追问“不对”具体在哪里，再对照确认图判断是意图理解、素材、布局、组合效果还是执行错误。确定本轮一组调整及保留项，出相关画面示意确认，再进入下一轮。记录否决原因，避免在下一轮重复同一错误；用户明确要求重新探索时，也仅重新打开指定范围及必要依赖。

## 预算

每轮建议候选数、生成量、采集量、较耗时环节及停止条件，用户可直接接受或调整。不确定的耗时如实标明。复用合格结果，技术失败先诊断，输入／方法／条件没有有效变化时不机械重试。预算不足时提出取舍，不能降低已确认质量而不说明。
