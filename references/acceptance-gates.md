# 商店素材交付门槛

在制作前展开这 41 类，结合项目细则，为每项绑定检查对象、通过条件、证据和状态。最小单位是「版位 × 本地化 × 设备 × 页 × 组件」，只在实际共享且输入指纹一致时复用证据。项目可细分条目，阈值、尺寸、图数、版本和具体素材由项目配置。

状态为通过、失败、未核验和不适用。不适用必须写明客观理由。任一适用项失败或缺证据，拦截对应交付批次。若用户只要求修指定文件，冻结其他已验收文件并比较哈希，复验受改动影响的条目及共享组件。若发现范围外的阻断项，按原授权保留文件，明确区分本轮合格的替换页和未通过的整套。样张和定稿都遵守各自交付范围内的门槛。

| # | 类别 | 过关条件 |
|---:|---|---|
| 01 | 交付矩阵 | 版位、设备、语言、页序、命名、数量与交付范围匹配。 |
| 02 | 确认基线 | 锁定经确认的主母版、场景、功能和不可变层，逐项核对授权差分。 |
| 03 | 构建身份 | 确认 App 源版本、构建号及入口；记录安装前后可执行文件或等价身份。 |
| 04 | 设备安装 | 每个采集设备实际运行对应构建，核尺寸、系统和设备配置。 |
| 05 | 采集隔离 | 同设备串行，核对前台 App、语言、导入素材、顺序和来源。 |
| 06 | 功能真实性 | 状态、选中工具、输入和结果都能对应真实操作。示意图单独标明。 |
| 07 | 隐私与使用依据 | 对实际可见文本、头像、账号、状态栏和外部素材核对脱敏及使用范围。 |
| 08 | 资源可用性 | 所有图片、字体、遮罩可读取且加载完成，当前哈希对应母版引用。 |
| 09 | 源清晰度 | 关键文字和图标在原件及最终像素尺寸可读，低分辨率回源重采或重绘合规示意。 |
| 10 | 原生取景四边 | 按完整控件的外框取景，四边、内部说明、图标、勾选态均完整。 |
| 11 | 等比与采样 | 逐槽核比例和实际缩放，避免拉伸、二次缩放、过度锐化和错误裁剪。 |
| 12 | 网页渲染稳定 | 检查长画布、高密度和分数缩放中的重复平铺、缺图、错图、空白和双重渲染。 |
| 13 | 文案完整 | 确认实际画面没有遗漏、重复、遗留版本、错字和截断。 |
| 14 | 字体和字形 | 核对实际加载字体、回退字形、字重、行高及文字笔画。 |
| 15 | 文字边界 | 逐段检查可见文字是否越界、被圆角吃掉、互相叠印或侵入相邻层。 |
| 16 | 清晰与对比 | 按原尺寸检查高风险小字和图标，按商店缩略尺寸检查重点可辨性。 |
| 17 | 品牌和信息层级 | 缩略图主标题、图示、结果优先级明确，成品继承已批准的视觉层级。 |
| 18 | 机身和位置 | 机框版本、等比、基线和间距与设备规范一致，机身、阴影各有唯一来源。 |
| 19 | 遮罩及四角 | 逐角逐边查看裁切、白边、外溢、空屏和透明残影。 |
| 20 | 系统状态区 | 主屏状态栏、硬件开孔、语言和模态变暗相符，排除回跳标签及重复硬件。 |
| 21 | 屏内构图 | 核实导航、预览主体、工具条和真正的处理结果有足够可见面积。 |
| 22 | 瞬态与黑块 | 查全图及组件的黑屏、空图、加载、权限弹窗、键盘、短时提示和过渡残影。 |
| 23 | 组件数量与顺序 | 卡片、对照、放大层、条目与确认的场景逐个匹配。 |
| 24 | 卡片几何 | 测量实际边距、内距、宽高、旋转、阴影占用和旋转后的安全边界。 |
| 25 | 图层、阴影与遮挡 | 检查堆叠次序和实际背景混合，确保阴影、标记、引线不盖住关键信息。 |
| 26 | 跨组组件语义 | 同一功能卡的数据、前后关系和取景意图相同，语言和设备变化有依据。 |
| 27 | 真实结果完整性 | 回查实际输出的尺寸、开头、中间和结尾，排除选错缓存、漏段和重复段。 |
| 28 | 输入与流程准确 | 功能入口完整，步骤方向、编号、边界条件和文案与真实能力相符。 |
| 29 | 相似内容与关键细节 | 核对用例始终使用同类内容。接缝居中且上下相邻样本、月份或关键差异同时可见。 |
| 30 | 前后对照可比性 | 同源、同对象、同位置、同倍率。目标差异可见，邻近区域、宽度和标记能对上。 |
| 31 | 多处处理结果 | 有局部或批量修改时验证选择区域、处理到的各实例及邻近保留区域。 |
| 32 | 裁剪和标注 | 边框、把手、遮罩或箭头和文字指向图中实际对应的对象。 |
| 33 | 拆分及连续内容 | 有切片或分页时核对边界位置、相邻内容及原有文字是否完整。 |
| 34 | 格式或模式选择行 | 依据原生控件组取全行，核名称、说明、外框、选中态及在最终卡中的完整性。 |
| 35 | 本地化和系统语言 | 查当地措辞、单位、时间、数字、货币和实际前台语言，处理较长文本。 |
| 36 | 文件规范 | 对最终文件核对当期版位规定的像素尺寸、编码、位深、颜色、透明度及可解码性。 |
| 37 | 全画布像素检查 | 对每张成品做连贯像素覆盖，单独检查容易被整图平均值掩盖的小卡黑块和错误纹理。 |
| 38 | 跨组视觉和文字回看 | 同页跨语言和设备并排，辅以成品文字识别及风险区域原尺寸核对。 |
| 39 | 交付回读与回归 | 在交付路径重新读取最终文件，核数量、哈希、证据和复现记录。失败场景加入回归。 |
| 40 | 商店审核证据 | 确认目标版位的当期要求，逐组用最终 PNG 计算真实 App 使用页比例。 |
| 41 | 新手引导与延迟提示 | 普通功能图的原件和最终 PNG 均无未计划的引导文字、手势、轨迹或遮罩。进入最后一个目标状态后查连续稳定帧，采集前后核状态及画面。 |

## 把常见失误拦在对应步骤

- **真实画面先建立稳定窗口。** 操作本身会触发首次引导、后续引导、提示条或软键盘。无关效果按真实交互完成或等待结束，考虑自动接续出现的下一条。采集前后利用可见的 UI 层级、元素 ID 或文字，加上连续画帧观察。固定延时或单次层级缺席不足以证实干净。若分镜就是展示引导，则对预期引导名称、内容及停留状态单独核验。
- **证据把原件、组装、最终 PNG 串起来。** 按共用原生容器取控件四边和内文字，再追踪缩放、旋转和遮罩后的边界。对比或放大组件需确认标记落在同源位置。发现不够清楚时回源加强取景、曝光或源素材质量；把设计示意与真实处理结果分开记录。
- **文本与场景从同一母版派生。** 翻译生效前冻结语义、原始示例与组件顺序。查背景图是否带旧字、浏览器是否平铺、活跃会话是否仍在前一语言、原件是否含多个未使用的图层。
- **局部问题分别定位再验证。** 找到最早失效层，回到状态、原件、母版或交付文件处理。只在影响范围内重做，重跑失败用例、共享组件关联项和需要保持的哈希比较。像素、结构、文字识别和人工视觉各自记录，脚本通过不能替代没有覆盖的检查。
- **缺证据时挡住定稿。** 已匹配当前版本和输入指纹的有效记录可复用。无法完成的项列明影响和缺口；范围外旧图不会借本轮局部修正变成已复验的成品。
